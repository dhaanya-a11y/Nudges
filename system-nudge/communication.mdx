### Communication

After configuring the **Interaction Limit**, the **Communication** screen is displayed.

Use this step to define the communication trigger and configure the templates for the available communication channels.

#### Configure Communication Trigger

Configure the trigger details for the Nudge communication.

| Field | Description |
| --- | --- |
| **Trigger Name** | Enter a name for the communication trigger. |
| **Send on** | Select the date and time for the communication trigger. |
| **Repeat** | Select whether the trigger should repeat. |

Select **Add Trigger Date** to add another trigger date.

#### Configure Communication Channels

Configure the communication template for each available channel.

| Channel | Description |
| --- | --- |
| **EMAIL** | Email communication. |
| **SMS** | Text message communication. |
| **RCS** | Rich Communication Services messaging. |
| **WHATSAPP** | WhatsApp messaging. |

Select **Configure** for the required channel to configure its template.

Select **Add more** to add additional communication channels.

<div className="flex justify-center my-6">
  <img

After completing the configuration, select **Continue** to proceed to **Review**.
