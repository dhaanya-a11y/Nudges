## Overview

The **User Base** defines the group of customers who are eligible to receive the nudge.

In this step, configure the criteria used to identify the target users. The user base can be defined using attributes available under different entities such as **Customer**, **Account**, **Card**, and **Card Control**.

You can also estimate the number of users matching the configured criteria and configure additional controls for communication and duplicate accounts.

## Set Up Nudge User Base

### User Base

The **User Base** section allows you to define the conditions used to identify customers for the nudge.

Each criterion consists of:

- An **entity**, such as Customer, Account, Card, or Card Control.
- An **attribute** associated with the selected entity.
- The corresponding value or condition used to define the user base.

Select the required entity from the first dropdown and then select an attribute from **Select attribute**.

The attributes available in the second dropdown depend on the selected entity.

### Add Criteria

Select **Add Criteria** to add additional conditions to the user base.

Multiple criteria can be configured when the nudge needs to target users based on more than one condition.

Select **Customer** when the user base needs to be defined using customer-level information.

The available customer attributes include:

| Attribute | Description |
|---|---|
| **Date of Birth** | The customer's date of birth. This attribute can be used to identify customers based on their date of birth or age. |
| **KYC Status** | **KYC (Know Your Customer)** is the process of verifying a customer's identity. This attribute indicates the customer's current KYC verification status. |
| **FKYC Method** | **FKYC (Full KYC)** refers to the customer's full KYC verification. This attribute indicates the method through which the customer's FKYC was completed. |
| **FKYC Status** | Indicates the current status of the customer's **Full KYC (FKYC)** verification. |
| **Created On** | The date on which the customer's record was created in the system. |
| **Last Updated On** | The date on which the customer's record was most recently updated in the system. |

### Account Attributes

The following attributes are available for selection under **Account**:

- **Status** — Used to define a criterion based on the account status.
- **Smart Tag** — Used to define a criterion based on the Smart Tag associated with the account.
- **Statement Due Date** — Used to define a criterion based on the account's statement due date.
- **Created On** — Used to define a criterion based on the account creation date.
- **Last Updated On** — Used to define a criterion based on the date the account was last updated.
- **Account Block Codes** — Used to define a criterion based on the block codes associated with the account.

### Add Account Criteria

Select the required attribute from the **Account** attribute dropdown and configure the corresponding condition.

Select **Add Criteria** to add additional conditions to the user base.

### Available Card Attributes

The following attributes can be selected when defining criteria for the card:

#### Card Status and Identification

- **Status** — Select a criterion based on the card's status.
- **Smart Tag** — Select a criterion based on the Smart Tag associated with the card.
- **Card Type** — Select a criterion based on the card type.
- **Card Block Codes** — Select a criterion based on the block codes associated with the card.

#### Card Lifecycle

- **Card Expiry** — Select a criterion based on the card's expiry.
- **Physically Issued** — Select a criterion based on whether the physical card has been issued.
- **Virtually Issued** — Select a criterion based on whether the virtual card has been issued.
- **Physical Card Activated** — Select a criterion based on whether the physical card has been activated.
- **Virtual Card Activated** — Select a criterion based on whether the virtual card has been activated.
- **Is Ever Activated** — Select a criterion based on whether the card has ever been activated.

#### Card State

- **Locked** — Select a criterion based on whether the card is locked.
- **Blocked** — Select a criterion based on whether the card is blocked.

#### Record Information

- **Created On** — Select a criterion based on when the card record was created.
- **Last Updated On** — Select a criterion based on when the card record was last updated.
