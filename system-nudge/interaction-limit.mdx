### Interaction Limit

After configuring the **Display Elements**, the **Interaction Limit** screen is displayed.

Use this step to define how the Nudge is displayed based on user dismissal and interaction limits.

#### Configure Show Again After Dismissal

Configure whether the Nudge should be shown again after the user dismisses it.

| Field | Description |
| --- | --- |
| **Show Again After Dismissal** | Select whether the Nudge should be shown again after the user dismisses it. |

Once dismissed, the Nudge **won't show again**.

#### Configure Nudge Interaction Limit

Set a cap on user interactions, after which the Nudge stops appearing.

Select an **Attribute** to define the interaction limit.

| Attribute | Description |
| --- | --- |
| **Impression Count** | Number of times the Nudge is displayed to the customer. |
| **CTR Count** | Number of times the customer clicks the Nudge CTA. |

Select **Add more** to add additional interaction limits.

After completing the configuration, select **Continue** to proceed to **Communication**.
