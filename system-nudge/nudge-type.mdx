## Overview

The **Nudge Type** defines the mechanism used to trigger a nudge. It determines whether the nudge is triggered through system-based information, a customer file, or a touchpoint within a journey.

During nudge creation, choose the Nudge Type that corresponds to the required trigger mechanism.

Hyperface supports the following Nudge Types:

- **System Nudge**
- **File Upload**
- **Journey Nudge**

## Comparing Nudge Types

| **Consideration** | **System Nudge** | **File Upload** | **Journey Nudge** |
|-------------------|------------------|-----------------|-------------------|
| **Trigger Mechanism** | System-based triggers | `.csv` file | Journey touchpoints |
| **Information Used** | Customer parameters available in the system | Customer information provided in the file | Information from the customer journey |
| **Communication Context** | System-driven | File-based | Journey-based |
| **Key Characteristics** | Uses configured customer parameters | Uses a defined customer set provided through a file | Connects communication with the next step of a journey |

---

## System Nudge

A **System Nudge** uses **system-based triggers** to send a nudge.

The trigger can use customer parameters available in the system. Examples of these parameters include:

- **Card details**
- **Card status**
- **Date of birth**

These parameters can be used as part of the configured criteria for triggering the nudge.

### Example

A nudge needs to be triggered based on a customer's **card status**. The system uses the configured card-status information as part of the criteria for triggering the communication.

---

## File Upload

A **File Upload** nudge uses a **`.csv` file** to trigger nudges.

The uploaded file provides the customer information required for the nudge. This allows a defined customer set to be supplied through the file.

### Example

A bank has a predefined set of customers who need to receive a particular communication. The customer information is provided in a **`.csv` file**, which is then used to trigger the nudge for that customer set.

---

## Journey Nudge

A **Journey Nudge** uses **touchpoints within a customer journey** to send a nudge.

The nudge can be delivered through:

- **SMS**
- **WhatsApp**
- **Email**

The communication contains a link that directs the customer to a **landing page**. Information from the previous journey step is retained on the landing page, allowing the customer to proceed to the **next step**.

### Example

A customer reaches a configured touchpoint within a journey. A Journey Nudge sends the customer a communication through **SMS, WhatsApp, or Email** with a link to the landing page. The information from the previous journey step is retained, allowing the customer to continue to the next step.
