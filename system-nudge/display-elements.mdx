### Display Elements

After configuring the **User Base**, the **Display Elements** screen is displayed.

Use this step to define the appearance, content, and CTA of the Nudge in the PWA.

#### Configure Display Settings

Configure the basic display properties of the Nudge.

| Field | Description |
| --- | --- |
| **Enable Nudge Display** | Enable or disable the Nudge display. |
| **Nudge Labels** | Select labels to group Nudges. |
| **Nudge Variant** | Select the base display format of the Nudge. |
| **Location** | Select where the Nudge is displayed. |
| **Display Order** | Specify the display priority of the Nudge. |

#### Add a Display Illustration

Upload an illustration to be used with the Nudge.

The supported file formats are **PNG, JPG, JPEG, and GIF**. The maximum file size is **1 MB**, and the image must have a **1:1 ratio** with a recommended size of **400 × 400 pixels**.

Select **Upload** to add the illustration.

#### Configure Nudge Content

Define the content displayed to the customer in the PWA.

| Field | Description |
| --- | --- |
| **Nudge Heading** | Title of the Nudge displayed to the customer. |
| **Nudge Sub-Text** | Description of the Nudge displayed to the customer. |
| **Text on Button** | Text displayed on the CTA button. |

#### Customize Nudge Colors

Configure the colors used for the Nudge content and background.

| Field | Description |
| --- | --- |
| **Nudge Sub-Text Color** | Font colour of the sub-text. |
| **Nudge Heading Color** | Font colour of the heading. |
| **Background Color** | Background colour of the Nudge. |

#### Configure the CTA Redirection

Enter the **Redirection Link** associated with the CTA button.
