## Overview

**Nudge Scope** defines the basic information for the nudge and determines the card programs for which it will be applicable.

In this step, you configure the nudge's **name, description, duration, issuer, and program**. You can also choose whether the nudge should apply to all current and future card programs.

## Configure Nudge Scope

### Nudge Name

Enter the **Nudge Name** to identify the nudge.

- Use a name that clearly identifies the purpose of the nudge.
- **Example:** `Payment Reminder`

### Nudge Description

Enter a **Nudge Description** to provide additional information about the nudge.

- Describe the purpose or context of the nudge.
- Keep the description clear and relevant to the configured nudge.

### Nudge Duration

Define the period for which the nudge will be active.

- Select the **start date**.
- Select the **end date**.

### Issuer

Select the **Issuer** associated with the nudge.

- The Issuer represents the **credit card issuing bank**.
- Select the appropriate issuer from the available options.
---

## Configure Program Applicability

The **Program** field specifies the card program or programs for which the nudge will be applicable.

### Program

Select the required program or programs from the **Program** field.

Multiple programs can be selected when the same nudge needs to be applicable to more than one card program.

### Apply to All Current and Future Programs

The **Apply to all current and future programs** option allows the nudge to be applied across card programs without selecting them individually.

When enabled, the nudge applies to:

- All current card programs.
- Future card programs.

When the option is not enabled, select the specific programs for which the nudge should be applicable.

<Note>
Choose individual programs when the nudge is intended for specific card programs. Enable **Apply to all current and future programs** when the nudge should apply across all current and future card programs.
</Note>

## What's Next?
