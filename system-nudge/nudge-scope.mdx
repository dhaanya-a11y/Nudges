## Overview

**Nudge Scope** defines the basic details of the nudge and the programs for which the nudge will be applicable.

At this stage, you provide the nudge's name, description, active duration, issuer, and applicable program or programs.

## Configure Nudge Scope

### Nudge Name

Enter a **Nudge Name** to identify the nudge.

### Nudge Description

Enter a **Nudge Description** to provide information about the nudge.

### Nudge Duration

Set the **Nudge Duration** by selecting the start and end dates for which the nudge will be active.

### Issuer

Select the **Issuer**, which represents the credit card issuing bank associated with the nudge.

### Program

Select the **Program** or programs for which the nudge will be applicable.

The **Program** field allows you to select the applicable card programs.

### Apply to All Current and Future Programs

Enable **Apply to all current and future programs** when the nudge should apply to all current and future card programs.

When enabled, the setting applies the nudge to all current and future card programs.

<Note>
Configure the **Nudge Scope** based on the issuer and programs for which the nudge should be applicable.
</Note>

## Example

Suppose a nudge needs to be configured for a specific card program.

1. Enter the **Nudge Name** and **Nudge Description**.
2. Set the **Nudge Duration** using the required start and end dates.
3. Select the applicable **Issuer**.
4. Select the required **Program**.
5. If the nudge should apply to all current and future card programs, enable **Apply to all current and future programs**.

After completing the required scope details, select **Continue** to proceed to the next step.
