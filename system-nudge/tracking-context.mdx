## Overview

**Tracking Context** associates the nudge with the campaign or workflow in which it is used.

This step captures the following context:

- **Journey** — The journey associated with the nudge.
- **Batch** — The batch associated with the selected journey.
- **Offer Category** — The category of the offer associated with the nudge.
- **Offer Type** — The type of offer selected within the chosen category.
- **Offer** — The specific offer associated with the nudge.

The available selections are dependent on the values selected in the preceding fields.

## Journey and Batch

### Journey

Select the **Journey** associated with the nudge.

- Choose the required journey from the available options.
- The selected journey determines the batches available in the **Batch** field.

### Batch

Select the **Batch** associated with the selected journey.

- Choose the required batch from the available options.
- The available batches are populated based on the selected journey.
- The selected batch identifies the specific batch within that journey.

<Note>
Select the **Journey** before choosing the **Batch**, as the available batch options depend on the selected journey.
</Note>

## Offer Association

The **Offer Association** section connects the nudge to the relevant offer configuration.

### Offer Category

Select the **Offer Category** associated with the nudge.

The interface provides the following options:

- **Transactional Offer** — Available for selection.
- **Milestone Offer** — Displayed in the interface but currently disabled.

<Warning>
**Milestone Offer** is currently disabled and cannot be selected.
</Warning>

### Offer Type

Select the **Offer Type** based on the selected **Offer Category**.

The available offer types are determined by the selected offer category.

### Offer

Select the specific **Offer** associated with the nudge.

The selected offer establishes the offer association for the nudge.

## Selection Dependency

The fields follow two dependent selection paths:

**Journey → Batch**

**Offer Category → Offer Type → Offer**

The selection in each preceding field determines the options available in the field that follows.
