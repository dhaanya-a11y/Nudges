## Overview

**Tracking Context** defines the campaign or workflow context associated with the nudge.

In this step, you can associate the nudge with a **Journey**, **Batch**, and, where applicable, an **Offer**. These associations help identify where the nudge belongs and provide the context needed to track its performance.

## Configure Tracking Context

### Journey

The **Journey** field identifies the journey with which the nudge is associated.

- Select the required journey from the available options.
- The selected journey establishes the workflow context for the nudge.

### Batch

The **Batch** field identifies the batch within the selected journey.

- Select the required batch.
- The available batches are populated based on the selected journey.
- This associates the nudge with a specific batch in the journey.

## Associate an Offer

Use the offer fields to associate the nudge with a specific offer and its corresponding configuration.

### Offer Category

Select the **Offer Category** associated with the nudge.

The interface currently provides the following options:

- **Transactional Offer** — Available for selection.
- **Milestone Offer** — Currently disabled.

<Note>
The **Milestone Offer** option is displayed in the interface but is currently disabled and cannot be selected.
</Note>

### Offer Type

Select the **Offer Type** associated with the selected offer category.

The available options are determined by the selected **Offer Category**.

### Offer

Select the specific **Offer** associated with the nudge.

The selected offer establishes the offer-level context for the nudge and allows its performance to be tracked against that offer.

## Tracking Relationships

Tracking Context connects the nudge to the relevant campaign or workflow.

For a journey and batch:

**Journey → Batch → Nudge**

For an offer-associated nudge:

**Offer Category → Offer Type → Offer → Nudge**

These associations allow the nudge to be identified and evaluated within the appropriate journey, batch, or offer context.

## Example

A nudge is created as part of a customer journey and needs to be associated with a specific batch and offer.

1. Select the required **Journey**.
2. Select the **Batch** associated with that journey.
3. Select **Transactional Offer** as the **Offer Category**.
4. Select the relevant **Offer Type**.
5. Select the specific **Offer**.
6. Select **Continue** to proceed to the next step.

The configured context associates the nudge with the relevant workflow and offer, providing the required context for performance tracking.

<Warning>
**Milestone Offer** is currently disabled in the **Offer Category** selection and cannot be selected.
</Warning>
