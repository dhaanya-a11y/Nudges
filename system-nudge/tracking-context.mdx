## Overview

**Tracking Context** is used to associate a nudge with the campaign or workflow it belongs to.

The configuration is divided into two parts:

- **Journey and Batch** — identifies the workflow in which the nudge is being used.
- **Offer details** — identifies the offer associated with the nudge.

## Journey and Batch

### Journey

Select the **Journey** to which the nudge belongs.

The selected journey determines the workflow in which the nudge is being configured.

### Batch

Select the **Batch** associated with the selected journey.

The Batch field is populated based on the selected Journey, allowing the nudge to be linked to a specific batch within that journey.

<Info>
The **Batch** selection is dependent on the **Journey** selected above.
</Info>

## Offer Details

The offer section allows the nudge to be associated with the offer that is relevant to the campaign.

### Offer Category

Select the category of the offer associated with the nudge.

The interface currently shows:

- **Transactional Offer** — available for selection.
- **Milestone Offer** — disabled and unavailable for selection.

### Offer Type

Select the **Offer Type** associated with the selected offer category.

This field is used to narrow down the offer configuration before selecting the specific offer.

### Offer

Select the specific **Offer** that the nudge is associated with.

The selected offer provides the final offer-level reference for the nudge.

<Note>
**Milestone Offer** is currently disabled in the **Offer Category** field and cannot be selected.
</Note>

## Example

A nudge is being configured for a customer communication that belongs to a specific journey and batch and is associated with a transactional offer.

1. Select the required **Journey**.
2. Select the corresponding **Batch**.
3. Choose **Transactional Offer** under **Offer Category**.
4. Select the required **Offer Type**.
5. Select the relevant **Offer**.
6. Select **Continue**.

This completes the Tracking Context configuration and allows the nudge to move to the next stage of setup.
