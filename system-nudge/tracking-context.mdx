## Overview

**Tracking Context** connects the nudge to the campaign or workflow in which it is being used.

This step captures two types of context:

- **Journey and Batch** — identifies the journey and the specific batch associated with the nudge.
- **Offer Details** — associates the nudge with the relevant offer.

## Configure Journey and Batch

### Journey

The **Journey** field is used to select the journey associated with the nudge.

- Select the required journey from the dropdown.
- The selected journey determines the available batch options.

### Batch

The **Batch** field is used to select a batch within the selected journey.

- Select the required batch from the dropdown.
- The batch options are populated based on the selected journey.
- Selecting a batch associates the nudge with that specific batch.

<Note>
Select the **Journey** before selecting the **Batch**, as the available batches depend on the selected journey.
</Note>

## Configure Offer Details

Use the offer details section to associate the nudge with an existing offer.

### Offer Category

The **Offer Category** identifies the type of offer associated with the nudge.

The available options shown in the interface are:

- **Transactional Offer** — available for selection.
- **Milestone Offer** — currently disabled.

<Warning>
**Milestone Offer** is currently disabled and cannot be selected.
</Warning>

### Offer Type

Select the **Offer Type** associated with the selected offer category.

The available offer types are presented based on the selected category.

### Offer

Select the specific **Offer** associated with the nudge.

The selected offer completes the offer association for the nudge.

## Example

Suppose a nudge needs to be associated with a particular customer journey and a transactional offer.

1. Select the required **Journey**.
2. Select the corresponding **Batch**.
3. Select **Transactional Offer** under **Offer Category**.
4. Select the required **Offer Type**.
5. Select the relevant **Offer**.
6. Select **Continue**.

The nudge is now associated with the selected journey, batch, and offer context.
