## Overview

**Tracking Context** associates a nudge with the campaign or workflow in which it is used.

The configuration includes:

- **Journey** — identifies the journey associated with the nudge.
- **Batch** — identifies the batch within the selected journey.
- **Offer Category** — identifies the category of the associated offer.
- **Offer Type** — identifies the type of the selected offer.
- **Offer** — identifies the specific offer associated with the nudge.

## Journey and Batch

### Journey

Select the **Journey** associated with the nudge.

- Choose the required journey from the dropdown.
- The selected journey determines the batch options available for selection.

### Batch

Select the **Batch** associated with the selected journey.

- Choose the required batch from the dropdown.
- The available batches are populated based on the selected journey.
- The selected batch identifies the specific batch within the journey.

<Note>
The **Batch** options are dependent on the selected **Journey**.
</Note>

## Offer Association

The offer section links the nudge to the relevant offer configuration.

### Offer Category

Select the **Offer Category** associated with the nudge.

The interface provides the following options:

- **Transactional Offer** — available for selection.
- **Milestone Offer** — displayed but disabled.

<Warning>
**Milestone Offer** is currently disabled and cannot be selected.
</Warning>

### Offer Type

Select the **Offer Type** associated with the selected **Offer Category**.

The available options are based on the selected offer category.

### Offer

Select the specific **Offer** associated with the nudge.

The selected offer establishes the offer-level association for the nudge.

## Configuration Relationship

The fields follow a dependent selection flow:

**Journey → Batch**

and

**Offer Category → Offer Type → Offer**

This ensures that the nudge is associated with the appropriate journey, batch, and offer configuration.
