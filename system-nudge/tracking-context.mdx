## Overview

**Tracking Context** associates the Nudge with the campaign or workflow in which it is used.

This step includes the following:

- **Journey** — The journey associated with the Nudge.
- **Batch** — The batch associated with the selected journey.
- **Offer Category** — The category of the offer associated with the Nudge.
- **Offer Type** — The type of offer within the selected category.
- **Offer** — The specific offer associated with the Nudge.

The available options depend on the selections made in the preceding fields.

## Journey and Batch

### Journey

Select the **Journey** associated with the Nudge.

Choose the required journey from the available options. The selected Journey determines the batches available in the **Batch** field.

### Batch

Select the **Batch** associated with the selected Journey.

Choose the required batch from the available options. The available batches are populated based on the selected Journey.

The selected Batch identifies the specific batch within the Journey.

<Note>
Select the **Journey** before selecting the **Batch**, as the available Batch options depend on the selected Journey.
</Note>

## Offer Association

Use the **Offer Association** section to associate the Nudge with the relevant offer.

### Offer Category

Select the **Offer Category** associated with the Nudge.

The available options are:

- **Transactional Offer** — Available for selection.
- **Milestone Offer** — Displayed in the interface but currently disabled.

<Warning>
**Milestone Offer** is currently disabled and cannot be selected.
</Warning>

### Offer Type

Select the **Offer Type** based on the selected **Offer Category**.

The available offer types depend on the selected Offer Category.

### Offer

Select the specific **Offer** associated with the Nudge.

The selected Offer completes the offer association for the Nudge.

## What's Next?

After completing the **Tracking Context** configuration, select **Continue** to proceed to **User Base**.
