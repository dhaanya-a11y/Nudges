---
title: Tracking Context.
---

**Tracking Context** associates the Nudge with the relevant journey, batch, and offer.

This step includes the following:

- **Journey** — The journey associated with the Nudge.
- **Batch** — The batch associated with the selected Journey.
- **Offer Category** — The category of the offer associated with the Nudge.
- **Offer Type** — The type of offer within the selected category.
- **Offer** — The specific offer associated with the Nudge.

<Note>
The available options depend on the selections made in the preceding fields.
</Note>

## Journey and Batch

<Steps>
  <Step title="Select the Journey">
    Select the **Journey** associated with the Nudge. Choose the required Journey from the available options. The selected Journey determines the batches available in the **Batch** field.
  </Step>
  <Step title="Select the Batch">
    Select the **Batch** associated with the selected Journey. Choose the required Batch from the available options. The available batches are populated based on the selected Journey and identify the specific batch within the Journey.
  </Step>
</Steps>

<Warning>
Select the **Journey** before selecting the **Batch**, as the available Batch options depend on the selected Journey.
</Warning>

## Offer Association

Use the **Offer Association** section to associate the Nudge with the relevant offer.

<div className="flex justify-center my-6">
  <img
    src="/images/images/n5.1.png"
    alt="Offer association configuration"
    className="w-[700px] rounded-2xl border border-gray-200 shadow-lg"
  />
</div>

<Steps>
  <Step title="Offer Category">
    Select the **Offer Category** associated with the Nudge. The available options are:
    - **Transactional Offer** — Available for selection.
    - **Milestone Offer** — Displayed in the interface but currently disabled.
  </Step>
  <Step title="Offer Type">
    Select the **Offer Type** based on the selected **Offer Category**. The available offer types depend on the selected Offer Category.
  </Step>
  <Step title="Offer">
    Select the specific **Offer** associated with the Nudge. The selected Offer completes the offer association for the Nudge.
  </Step>
</Steps>

<Warning>
**Milestone Offer** is currently disabled and cannot be selected.
</Warning>

## What's Next?

After completing the **Tracking Context** configuration, select **Continue** to proceed to **User Base**.
