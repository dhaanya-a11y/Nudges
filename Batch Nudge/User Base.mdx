The **User Base** defines the group of customers who are eligible to receive the Nudge.

Use this step to configure the criteria that identify the target customers. Criteria can be based on attributes available under different entities, including **Customer, Account, Card, and Card Control**.

You can also estimate the number of customers matching the configured criteria and apply additional controls related to communication eligibility and duplicate accounts.

## Set Up the User Base

The **User Base** section allows you to define the conditions used to identify the customers who should receive the Nudge.

<Steps>
  <Step title="Select an entity">
    Choose an entity, such as Customer, Account, Card, or Card Control.
  </Step>
  <Step title="Select an attribute">
    Select an attribute associated with the chosen entity from **Select attribute**. The attributes available depend on the selected entity.
  </Step>
  <Step title="Define the value or condition">
    Provide the corresponding value or condition used to define the user base.
  </Step>
  <Step title="Add more criteria (optional)">
    Select **Add Criteria** to add additional conditions. Multiple criteria can be configured when the Nudge needs to target customers based on more than one condition.
  </Step>
</Steps>

## Additional User Base Controls

After defining the user-base criteria, configure the additional options related to communication eligibility and duplicate accounts.

<CardGroup cols={2}>
  <Card title="Override Do Not Communicate (DNC)">
    Enable to allow the Nudge to be sent to eligible customers who are part of the **Do Not Communicate (DNC)** list.
  </Card>
  <Card title="Allow Duplicate Accounts">
    Enable when duplicate accounts should be included in the Nudge's user base. By default, duplicate accounts are blocked to prevent customers from receiving multiple communications. Enable this option only for **pre-approved campaigns** where duplicate accounts are intentionally required.
  </Card>
</CardGroup>
