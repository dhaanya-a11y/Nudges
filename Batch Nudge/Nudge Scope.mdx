## Overview

**Nudge Scope** defines the basic details of the Nudge and the card programs to which it applies.

This step includes configuring the **Nudge Name, Nudge Description, Nudge Duration, Issuer, and Program**. You can also choose whether the Nudge applies to all current and future card programs.

## Configure Nudge Details

### Nudge Name

Enter a **Nudge Name** to identify the Nudge.

Use a name that clearly indicates its purpose.

**Example:** `Payment Reminder`

### Nudge Description

Enter a **Nudge Description** to provide additional information about the Nudge.

Describe its purpose or context using a clear and relevant description.

### Nudge Duration

Define the period during which the Nudge will be active.

- Select the **Start Date**.
- Select the **End Date**.

### Issuer

Select the **Issuer** associated with the Nudge.

The Issuer represents the **credit card issuing bank**. Select the appropriate issuer from the available options.

## Configure Program Applicability

The **Program** field determines the card program or programs to which the Nudge applies.

### Program

Select the required program or programs from the **Program** field.

- Select multiple programs when the same Nudge needs to apply to more than one card program.
- When specific programs are selected, the Nudge applies only to those programs.

### Apply to All Current and Future Programs

Enable **Apply to all current and future programs** when the Nudge should apply across card programs without selecting each program individually.

When enabled, the Nudge applies to:

- All current card programs.
- Future card programs.

When this option is not enabled, select the specific programs to which the Nudge should apply.

## What's Next?

After completing the **Nudge Scope** configuration, select **Continue** to proceed to **Tracking Context**.
