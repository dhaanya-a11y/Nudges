## Overview

The **Nudge Type** defines how a nudge is configured and how it is triggered.

When creating a nudge, select the Nudge Type that best matches the requirement for identifying customers and triggering the communication.

Hyperface provides the following Nudge Types:

- **System Nudge**
- **File Upload**
- **Journey Nudge**
- **Promotional Nudge**

## Comparing Nudge Types

| **Nudge Type** | **Description** |
|----------------|-----------------|
| **System Nudge** | Uses system-based triggers to send a nudge. |
| **File Upload** | Uses a **`.csv` file** to trigger nudges. |
| **Journey Nudge** | Uses touchpoints within a journey to send a nudge. |
| **Promotional Nudge** | Uses datapoints across offers to trigger a nudge. |

---

## System Nudge

A **System Nudge** uses **system-based triggers** to send a nudge.

The nudge can use customer parameters as part of the configured criteria. Customer parameters can include information such as **card details, card status, and date of birth**.

System Nudges are used when the nudge needs to be triggered using system-based information and configured customer parameters.

<Info>
Select **System Nudge** when the nudge needs to be triggered using system-based triggers and customer parameters.
</Info>

---

## File Upload

A **File Upload** nudge uses a file in **`.csv` format** to trigger nudges.

The file contains the customer information required for the nudge. This allows a defined set of customers to be provided through a file for the nudge.

<Info>
Select **File Upload** when the customers for the nudge are provided through a **`.csv` file**.
</Info>

---

## Journey Nudge

A **Journey Nudge** uses **touchpoints within a journey** to send a nudge.

The nudge can be sent through **SMS, WhatsApp, or Email** with a link that directs the customer to a **landing page**.

Information from the previous journey step is retained on the landing page, allowing the customer to proceed to the **next step** of the journey.
