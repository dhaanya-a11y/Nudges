## Start Creating a Nudge

To begin creating a nudge, go to the **Home** page and select **Create a Smart Nudge**.

<img
  src="/images/n1.png"
  alt="Create a Smart Nudge option on the Home page"
  style={{height: "300px", width: "400px"}}
  className="rounded-lg"
/>

Selecting **Create a Smart Nudge** takes you to the **Manage Nudges** page, where you can select the nudge flow based on your requirement.

---

## Select the Nudge Type

On the **Manage Nudges** page, select the appropriate nudge type:

- **Batch Nudges**
- **Event-Based Nudges**

For this guide, select **Batch Nudges**.

  src="/images/n2.png"

### Batch Nudges

**Batch Nudges** are used to send the **same nudge to a defined set of customers at the same time**.

The customer set is determined based on the configured **eligibility criteria**. A file of eligible customers is generated based on these criteria, and the same nudge is sent to all customers in the generated file at the same time.

<Info>
Use **Batch Nudges** when you need to send the same nudge to a customer set identified through the configured eligibility criteria.
</Info>

---

## Create a New Batch Nudge

After selecting **Batch Nudges**, select **+ Create New Nudge** to begin configuring the nudge.

Selecting **+ Create New Nudge** takes you to the next step of the Batch Nudge creation process.

<Note>
The subsequent steps allow you to configure the Batch Nudge before it is sent to the eligible customer set.
</Note>
