## Start Creating a Nudge

To begin creating a nudge, go to the **Home** page and select **Create a Smart Nudge**.

Selecting **Create a Smart Nudge** takes you to the **Manage Nudges** page.

---

## Select the Nudge Type

On the **Manage Nudges** page, select the nudge type based on your requirement:

- **Batch Nudges**
- **Event-Based Nudges**

For this guide, select **Batch Nudges**.

### Batch Nudges

**Batch Nudges** are used when the **same nudge needs to be sent to a defined set of customers at the same time**.

The customer set is determined based on the configured **eligibility criteria**. A file of eligible customers is generated based on these criteria, and the same nudge is sent to all customers in the generated file at the same time.

<Info>
Use **Batch Nudges** when the same nudge needs to be sent to a customer set generated based on the configured **eligibility criteria**.
</Info>

---

## Create a Batch Nudge

After selecting **Batch Nudges**, click **+ Create New Nudge** to start creating the Batch Nudge.
