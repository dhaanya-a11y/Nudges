## Start Creating a Nudge

To start creating a nudge, navigate to the **Home** page and select **Create a Smart Nudge**.

Selecting **Create a Smart Nudge** opens the **Manage Nudges** page.

## Select the Nudge Type

On the **Manage Nudges** page, select the required nudge type:

- **Batch Nudges**
- **Event-Based Nudges**

For this guide, select **Batch Nudges**.

### Batch Nudges

**Batch Nudges** are used when the same nudge needs to be sent to a defined set of customers at the same time.

The customer set is determined using the configured **eligibility criteria**. Based on these criteria, a file containing the eligible customers is generated, and the same nudge is sent to all customers in the generated file at the same time.

<Info>
Use **Batch Nudges** when the same nudge needs to be sent to a customer set generated using the configured **eligibility criteria**.
</Info>

## Create a Batch Nudge

After selecting **Batch Nudges**, select **+ Create New Nudge** to begin configuring the Batch Nudge.

The nudge creation flow then takes you through the configuration steps required to define the nudge.
